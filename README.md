# KAYRA Terminal

A huge, solid-red `KAYRA` wordmark appears at the top of each new terminal session. A tiny superscript `kayralrics.com` sits beside it.

## Install

```bash
git clone https://github.com/YOUR_USERNAME/kayra-terminal.git
cd kayra-terminal
chmod +x install.sh uninstall.sh
./install.sh
```

Open a new terminal to see the banner. The installer supports Bash, Zsh, and Fish, and creates a backup of the shell configuration file before changing it.

## Uninstall

```bash
./uninstall.sh
```

The banner uses bright red ANSI color and requires no external packages or fonts.
